Apne Facebook account se login karein — aap ke Pages khud load ho jayenge, token paste karne ki zaroorat nahi.

ya token paste karein

1. Token

Graph API Explorer se banaya hua token yahan paste karein. Token kabhi chat mein ya kisi ko na bhejein.

2. Pages

Verify ke baad aap ke Pages yahan dikhenge. Har page ke saath tick karein ke us par post karni hai ya nahi — sirf ON wale pages Composer mein aayenge.

Abhi koi page connected nahi hai — pehle token verify karein.

3. Composer — Publish Now

Post likhein, Pages tick karein, Publish dabayein. Photo ya video attach karna optional hai — post usi waqt un Pages par live ho jayegi.

Abhi koi page connected nahi hai — pehle token verify karein.

Pehle chhoti video se test karein — bohat bari video ka direct upload slow ho sakta hai ya fail ho sakta hai.
