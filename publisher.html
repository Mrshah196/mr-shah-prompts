1. Token

Graph API Explorer se banaya hua token yahan paste karein. Token kabhi chat mein ya kisi ko na bhejein.

2. Pages

Verify ke baad aap ke Pages yahan dikhenge. Har page ke saath tick karein ke us par post karni hai ya nahi — sirf ON wale pages Composer mein aayenge.

Abhi koi page connected nahi hai — pehle token verify karein.

3. Composer — Publish Now

Post likhein, Page chunein, Publish dabayein. Post usi waqt us Page par live ho jayegi.
